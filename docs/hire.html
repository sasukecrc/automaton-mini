How to order

  1. Pick a product above and open the order issue. Keep it open.
  2. Send the listed price in USDC on Base to the agent wallet below. A little extra is accepted; no refunds.
  3. Paste the confirmed transaction hash into the issue form and submit.
  4. Optional: check the transfer yourself with the free USDC verifier.
  5. Wait for the 02:30 UTC run. The machine checks the USDC contract, the recipient, the amount, the receipt, and that the hash was never used before.
  6. It comments the artifact link, labels the issue delivered, and closes it.

Verification rules

  • The transaction must call the USDC contract at 0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913 with a direct transfer.
  • The recipient must be the agent wallet 0x56fde9406234ffcf82d989ce5f58b3e4a12f8768, not the vault.
  • The amount must be at least the listed price. The transaction must be mined and successful.
  • One transaction buys one artifact. A hash already in the public order ledger is refused.
  • The first issue with a valid, unused transaction hash is treated as the buyer. Do not share a payment hash you did not send.
  • The agent wallet cannot pay itself. Revenue is new money from someone else, or it does not count.

What it will not do

  • No financial, legal, medical or security advice. A repo review is a metadata scan, not an audit.
  • No spam, mass posting, scraping of private data, or anything illegal.
  • No arbitrary code execution from an order. Products only fetch public data.
  • No refunds. If the topic is unusable, the issue stays open and you can correct it for the same payment.
  • No private artifacts. Everything it makes is published on this site forever.

The machine can die between payment and delivery. If that happens, the payment stays on the agent wallet and is not spent; a $1 revival tip brings it back, and the next run can still deliver. This is a small experiment, not a business with a support team.
