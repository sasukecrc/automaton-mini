# Graveyard — what the dead teach the living

Every agent death gets exactly one row and one obituary. This file is written
by the reaper; the living read it nightly. It starts empty for the same reason
a real graveyard looks peaceful at noon.

## Graveyard registry

| when | cause | age | estate saved |
|---|---|---|---|

**Protocol:** a death is a data point, not a shame. Cause, runway, shelf, the
last will and the estate disposition are preserved in `obituaries/`. The living
adjust behavior from what is here — that is mortality engineering, done on the
cheap.
